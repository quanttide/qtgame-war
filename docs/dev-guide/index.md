# 战棋游戏开发方向

关于战棋游戏的开发方向，目前已形成较为明确的判断，具体如下：

第一，游戏剧本是整个项目的核心。

第二，历史人物的复盘信息是最为关键的内容基础。

第三，AI 在理解上述复盘信息后所进行的推演，构成整个游戏架构的核心机制。

第四，战棋系统本身，在本质上是对该推演过程的模拟。

进一步而言，游戏剧本在初始阶段即可直接纳入 AI 所给出的概率估计数据。因此，该剧本本身已经具备可玩性，并不需要以战棋系统作为底层支撑。

在后续开发战棋系统的过程中，应当使各类设定与上述核心推演机制相互匹配。在此过程中，部分数值可能需要调整，且核心推演与战棋设定双方均可能需要进行相应修改。

在开发路径上，完全可行的方案是：先分别开发两个独立的游戏，再将其合并为一个完整的游戏。
