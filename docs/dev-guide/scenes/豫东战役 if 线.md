好，用同一套框架扫描豫东战役（1948年6月—7月）。这场战役在你方法论视角下非常有意思，因为它是**粟裕“斗胆直陈”之后的第一次战略验证战**，而且整场战役的形态在16天里翻转了三次——每一次翻转背后都有一个高质量的可复现支点。
先交代一下战役骨架，不然节点没法定位：
**历史上的豫东战役三阶段**：
1. **第一阶段（6月17-22日）**：粟裕以第3、8纵队“攻城打援”佯攻开封，实际主力准备打邱清泉兵团——结果陈锡联（华野3纵、8纵）**竟然真把开封攻下来了**（河南省会，守军约3万），打乱了原计划，也震撼了南京；
2. **第二阶段（6月26日—7月2日）**：蒋介石严令各兵团夺回开封，邱清泉、区寿年两兵团追击华野“撤退”部队——粟裕突然回马枪，**在睢杞地区把区寿年兵团（约5万人）包了饺子**，区寿年被俘；
3. **第三阶段（7月2-6日）**：黄百韬兵团（从山东方向奔袭而来，2.5万人）意外插入帝丘店，与被围的72师会合——粟裕在未完全消化区兵团的情况下，**再赌一把，围攻黄百韬**——打了一个两线夹击的险局，最后在黄百韬发起反击、胡琏兵团即将抵达时**主动收兵撤出**，带着俘虏和战果全身而退。
全程华野约20万对国民党军约25万（分批到达），歼敌约9万。粟裕自己评价这是他一生打得最险的一仗，毛泽东战后说“我们过了山坳子”。

## 可复现支点扫描
豫东战役的可复现节点比淮海更密集，因为它每3-5天就出现一次决策翻转。按质量排序：
### 支点一：粟裕不打邱清泉，改打区寿年——“临阵换靶”
**决策时刻**：6月26日前后，邱清泉兵团直进开封，区寿年兵团在睢杞地区**迟疑不进**（区判断华野还有后手，所以停了下来）——两个兵团之间瞬间拉开了40公里的空隙。
**粟裕的赌博**：放弃原计划（打邱清泉），主力突然东转，扑向区寿年。这个决策的险处在于：邱清泉兵团距区兵团只有一天多行程，一旦不能速歼区兵团，华野将陷入邱、区、胡琏三面夹击。
**可推演的反事实**：**如果区寿年不犹豫，紧跟邱清泉队形**——两个兵团间隔不超过20公里，互相能听到炮声，粟裕没有任何分割穿插的窗口。豫东战役就会变成华野与两个兵团的正面消耗战，粟裕大概率收兵退回鲁西南，豫东战役根本不会发生。
**结构结论**：这个支点暴露的是国民党军一个致命的战术文化——**兵团司令在运动中的“安全本能”压倒协同意识**。区寿年停下来，是因为他害怕中埋伏；而邱清泉一路猛进，是因为他急着抢收复开封的头功。**两个兵团一个太怂一个太抢，中间的空隙就是粟裕全部的战机**。这类“协同空隙”在孟良崮（张灵甫突进、两翼观望）、碾庄（黄百韬孤悬）、双堆集（黄维孤军）反复出现——它是国民党军“派系分兵、见死不救”文化的物理表现。
