# studio ROADMAP

## v0.1.0 — 龙王店战斗（可玩闭环）

**目标**：把 `examples/prototype/龙王店战斗.html` 的完整玩法在 studio（Flutter）中实现。该原型是玩法事实源，v0.1.0 的验收以与原型逐机制等价为准。

### 剧本数据

- [ ] 龙王店地图：8×7 六角格，地名（龙王店[要塞]、铁佛寺、帝丘店、田花园、杨拐）入 `assets/campaigns/longwangdian/`
- [ ] 华野 4 纵队（1纵/4纵/6纵18师[ assault 角色 ]、11纵[reserve 角色]）+ 国军整25师（逐回合推进）+ 整72师（背景压力）
- [ ] 5 回合时间轴（20:00–03:00）与逐回合史实事件文案

### 回合结构（每回合）

- [ ] 矛盾提示（按战局动态生成：援军距离 / 疲劳 / 工事值）
- [ ] 决心卡：2–3 个互斥方案，点卡即套用整套命令
- [ ] 命令档位微调：点算子在其可用档位间循环（攻城组 assault/siege/feint，阻援组 block/flank/lure/standby/assault）
- [ ] 结算 → 战报（含 D6 与伤害判断规则）→ 下一回合

### 规则机制（结算逻辑，须有单元测试）

- [ ] 7 档命令（TASK）：各自 atkMod / 疲劳增量
- [ ] d6 结算：强攻/围困/佯攻打工事，正面/侧翼/诱敌制整25师，守军反击
- [ ] 疲劳与轮换：fat≥4 战力惩罚，standby 恢复，建议按钮自动轮换
- [ ] 整25师：第 3 回合入场，逐回合推进，阻击/包抄/诱敌/佯攻对推进的修正，冒进遭伏，抵近冲阵
- [ ] 胜负：克工事（俘区寿年）/ 两部失去战斗力 / 天亮未克

### 界面

- [ ] 六角格地图（自适应、地名、算子色即档位）
- [ ] 决心卡面板 + 算子点击换档 + 建议按钮
- [ ] 战报渐进披露、回合横幅（时刻 + 史实事件）、胜负结算与重开

### 非目标（v0.1.0 不做）

- LLM 参谋长（Phase C2）、情报系统（Phase C1）、命令协议通用化（Phase C3）
- 三栏指挥部界面改造——v0.1.0 按原型的「地图 + 决心卡」单屏结构实现
