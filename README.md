# qtgame-war

量潮战旗游戏 — 一个"指挥官视角"的回合制战棋游戏，以豫东战役为切入。

## 核心设计

- **游戏类型**：回合制战棋 + 指挥官视角决策模拟
- **两种玩法，共用同一引擎**：
  - **互动剧本模式**：以指挥官看板为界面，情报迷雾 + 意图驱动 + 不可逆命令（"你在司令部里做决策，兵棋引擎在后方跑"）
  - **兵棋推演模式**：战场上帝视角，直接点棋子操作，传统战棋玩法（当前代码已实现的部分）
  - 两者底层共享同一个六角格兵棋引擎（移动/攻击/地形/战斗结算）
- **技术选型**：Flutter（建模阶段），零外部依赖
- **渲染方式**：六角格地图（依赖 hex_toolkit）
